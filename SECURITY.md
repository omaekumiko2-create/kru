# Security

KRU is designed to keep saved secret values out of normal MCP parameters, responses, audit records, and LLM context. It is not a sandbox and does not defend against a malicious local process, a compromised browser, or a hostile Agent that deliberately focuses the wrong target.

Please report suspected vulnerabilities privately through GitHub Security Advisories. Do not include real credentials, vault files, backups, or master-key files in an issue.

Before sharing diagnostics, confirm that they contain no account names, tokens, passwords, private keys, API responses, terminal output, or local paths that you consider private.
